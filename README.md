# WeatherPocket ☁️

Русскоязычный Telegram-бот: текущая погода и прогноз на три дня. Python 3.11+, SQLite и стандартная библиотека Python — внешние Python-пакеты не нужны.

## Возможности

- Поиск городов на русском и латинице; выбор из нескольких совпадений.
- Температура, ощущаемая температура, влажность, ветер и погодные условия.
- Прогноз на три дня: минимум/максимум температуры и вероятность осадков.
- Кнопки «Сейчас», «На 3 дня», «Сменить город», «Помощь».
- Сохранение города отдельно для каждого личного чата; `/forget` удаляет настройки.
- Кэш погоды на 10 минут, сетевые таймауты, повтор запросов Telegram при временных сбоях.
- Сохранение позиции polling и очереди ответов в SQLite.

## Запуск за несколько минут

1. Установите Python 3.11 или новее.
2. Создайте бота у официального [@BotFather](https://t.me/BotFather) командой `/newbot`. Полученный токен держите в секрете.
3. Скачайте репозиторий или клонируйте его:

```console
git clone https://github.com/spider-man-off/weather-pocket.git
cd weather-pocket
```

PowerShell — безопасный ввод токена без сохранения в истории команд:

```powershell
$botSecret = Read-Host 'Telegram bot token' -AsSecureString
$env:BOT_TOKEN = [System.Net.NetworkCredential]::new('', $botSecret).Password
python -m weather_pocket
```

Linux/macOS (Bash):

```bash
read -rs -p 'Telegram bot token: ' BOT_TOKEN; echo
export BOT_TOKEN
python -m weather_pocket
```

Откройте личный чат с ботом, нажмите Start и отправьте `Новосибирск`. Выберите номер города, если бот предложит несколько вариантов. Остановка: Ctrl+C. После остановки процесса бот не отвечает; GitHub только хранит исходники.

## Команды

| Команда | Действие |
|---|---|
| `/start`, `/help` | Справка |
| `/city Москва` | Поиск и сохранение города |
| `/weather` | Текущая погода в сохранённом городе |
| `/forecast` | Прогноз на три дня |
| `/cancel` | Отмена выбора города |
| `/forget` | Удаление настроек пользователя |

Можно просто отправить название города. Бот работает только в личных чатах, фото и сообщения групп игнорируются. Температура в °C, ветер в м/с; время соответствует часовому поясу выбранного города.

## Настройки

| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | Обязательный токен Telegram |
| `WEATHER_DB` | Путь к SQLite, по умолчанию `data/weather.sqlite3` |

Файл `.env` Python-приложение автоматически не читает. Он используется только Docker Compose. Не добавляйте токены и локальную базу в Git.

## Docker

Скопируйте `.env.example` в `.env` и локально заполните `BOT_TOKEN`. Затем:

```console
docker compose up -d --build
docker compose logs -f
docker compose down
```

База хранится в отдельном Docker volume и переживает пересоздание контейнера. Команда `docker compose down -v` удаляет и базу. Не запускайте одновременно две копии бота с одним токеном.

## Проверка

```console
python -m unittest discover -s tests -v
```

Тесты работают без сети и токена: команды, выбор города, изоляция пользователей, SQLite, кэш, ошибки, повтор доставки, polling и форматирование. GitHub Actions запускает их на Python 3.11 и 3.13.

## Архитектура

```text
weather_pocket/
  __main__.py   переменные окружения и запуск
  telegram.py   Telegram Bot API, long polling, отправка и повторы
  bot.py        команды и сценарий выбора города
  weather.py    Open-Meteo API, кэш и форматирование
  storage.py    SQLite: города, варианты, очередь ответа, offset
tests/          автономные тесты
```

Приложение работает последовательно, без веб-сервера и входящих портов. Внешние HTTP-запросы выполняются через `urllib.request`; SQL-запросы используют параметры. Компоненты погоды и Telegram заменяются заглушками в тестах.

## Данные, ограничения и статус

Погода и геокодирование предоставляются [Open-Meteo](https://open-meteo.com/), географические данные — GeoNames. API погоды не требует ключа для бесплатного некоммерческого использования; перед коммерческим размещением проверьте [условия](https://open-meteo.com/en/terms) и лимиты. Данные погодных моделей могут отличаться от измерений ближайшей станции. Атрибуция источника присутствует в каждом прогнозе.

SQLite хранит Telegram chat ID, выбранный город, варианты поиска и временно неотправленный ответ. Название города/координаты уходят в Open-Meteo; Telegram chat ID туда не передаётся. Текст сообщений и токен не пишутся в логи. `/forget` удаляет город и варианты поиска; доставленные ответы удаляются из локальной очереди. История сообщений в Telegram этой командой не удаляется.

Это учебный проект, подготовленный с помощью AI. Не заявляется промышленная эксплуатация. Локальные тесты не заменяют проверку с настоящим Telegram-токеном. Docker-конфигурацию нужно проверить в своей среде. Для небольшой личной нагрузки; запросы пользователей обрабатываются последовательно, сбой погодного API может задержать обработку до таймаута. При неопределённом результате сетевой отправки ответ может прийти повторно. Между сохранением выбора города и постановкой ответа в очередь остаётся небольшое окно сбоя процесса; повторный выбор города восстанавливает сценарий. Кэш очищается при перезапуске.

Если Telegram возвращает 401 — проверьте токен; 409 — остановите другую копию. Если настроен webhook, приложение откажется запускать polling: сначала отключите webhook для этого бота самостоятельно, если он больше не используется.

Документация: [Telegram Bot API](https://core.telegram.org/bots/api), [прогноз Open-Meteo](https://open-meteo.com/en/docs), [геокодирование](https://open-meteo.com/en/docs/geocoding-api).
