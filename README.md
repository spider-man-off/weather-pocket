# WeatherPocket ☁️

**Погода в нужном городе — прямо в Telegram.**

WeatherPocket показывает текущую погоду и прогноз на три дня. Достаточно выбрать город один раз: бот запомнит его и будет выдавать прогноз по нажатию кнопки.

[![Tests](https://github.com/spider-man-off/weather-pocket/actions/workflows/tests.yml/badge.svg)](https://github.com/spider-man-off/weather-pocket/actions/workflows/tests.yml)

## Возможности

- **Погода сейчас:** температура, ощущаемая температура, влажность, ветер и погодные условия.
- **Прогноз на три дня:** минимальная и максимальная температура, вероятность осадков.
- **Поиск города:** названия на русском и латинице, выбор из нескольких совпадений.
- **Быстрый доступ:** кнопки «Сейчас», «На 3 дня», «Сменить город» и «Помощь».
- **Личные настройки:** отдельный город для каждого пользователя, сохранение между перезапусками.
- **Удаление настроек:** команда `/forget` сбрасывает сохранённый город и варианты поиска.

Температура отображается в °C, скорость ветра — в м/с. Время соответствует часовому поясу выбранного города. Бот работает в личных чатах.

## Как пользоваться

1. Отправить `/start` в чат с запущенным ботом.
2. Ввести название города, например `Новосибирск`.
3. Выбрать номер, если найдено несколько мест.
4. Нажать «Сейчас» или «На 3 дня».

Для смены города достаточно отправить новое название или воспользоваться кнопкой «Сменить город».

| Команда | Назначение |
|---|---|
| `/start`, `/help` | Справка и список команд |
| `/city Москва` | Найти и сохранить город |
| `/weather` | Погода сейчас |
| `/forecast` | Прогноз на три дня |
| `/cancel` | Отменить выбор города |
| `/forget` | Удалить сохранённые настройки |

## Установка и запуск

**Требования:** Python 3.11+, доступ к интернету и токен Telegram-бота от [@BotFather](https://t.me/BotFather). Внешние Python-пакеты не требуются.

```console
git clone https://github.com/spider-man-off/weather-pocket.git
cd weather-pocket
```

### Windows · PowerShell

```powershell
$botSecret = Read-Host 'Telegram bot token' -AsSecureString
$env:BOT_TOKEN = [System.Net.NetworkCredential]::new('', $botSecret).Password
python -m weather_pocket
```

### Linux / macOS · Bash

```bash
read -rs -p 'Telegram bot token: ' BOT_TOKEN; echo
export BOT_TOKEN
python -m weather_pocket
```

Бот принимает сообщения, пока работает процесс. Остановка — `Ctrl+C`. Для постоянной доступности приложение размещается на сервере.

### Docker Compose

Создать `.env` по образцу `.env.example` и указать в нём токен:

```dotenv
BOT_TOKEN=your_telegram_bot_token
WEATHER_DB=/data/weather.sqlite3
```

Запуск:

```console
docker compose up -d --build
```

Логи и остановка:

```console
docker compose logs -f
docker compose down
```

Настройки сохраняются в Docker volume. Команда `docker compose down -v` удаляет volume вместе с базой.

## Конфигурация

| Переменная | Описание | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | Токен Telegram-бота | Обязательная |
| `WEATHER_DB` | Путь к базе SQLite | `data/weather.sqlite3` |

При запуске через Python параметры передаются через переменные окружения; `.env` автоматически читает только Docker Compose. Токены и локальные базы исключены из Git через `.gitignore`.

На один токен должен работать один polling-процесс. Если у бота настроен webhook, перед запуском его необходимо отключить: приложение не меняет эту настройку автоматически.

## Технологии

**Python · Telegram Bot API · Open-Meteo · SQLite · Docker · GitHub Actions**

Бот получает сообщения через long polling, поэтому не требует публичного HTTP-сервера и входящих портов. Погодные ответы кэшируются на 10 минут. При временных ошибках Telegram запросы повторяются, а неотправленный ответ и позиция обработки сохраняются в SQLite.

```text
weather_pocket/
  __main__.py   запуск приложения
  bot.py        команды и выбор города
  weather.py    погодный API, кэш и форматирование
  telegram.py   получение и отправка сообщений
  storage.py    настройки и очередь ответов в SQLite
tests/
  test_weather.py
```

## Тестирование

```console
python -m unittest discover -s tests -v
```

19 автономных тестов проверяют команды, выбор города, изоляцию пользователей, сохранение данных, кэширование, обработку ошибок и повтор доставки. Сеть и токен для тестов не нужны. GitHub Actions выполняет проверки на Python 3.11 и 3.13.

## Источники данных и приватность

Погода и поиск городов — [Open-Meteo](https://open-meteo.com/), географические данные — GeoNames. Ссылка на источник включена в каждый прогноз. Условия использования API опубликованы на [сайте Open-Meteo](https://open-meteo.com/en/terms).

Для поиска и получения прогноза в Open-Meteo передаются название города и его координаты, без Telegram ID. Локальная база содержит ID чата, выбранный город, варианты поиска и временно неотправленный ответ. Токены и сообщения пользователей не записываются в логи.

`/forget` удаляет сохранённый город и варианты поиска. Доставленные ответы удаляются из локальной очереди; история чата в Telegram сохраняется.

## Особенности работы

- Прогноз основан на погодных моделях и может отличаться от показаний ближайшей метеостанции.
- Запросы обрабатываются последовательно; приложение рассчитано на небольшую нагрузку.
- При сетевом сбое возможна повторная доставка ответа. Если процесс прервётся во время выбора города, может потребоваться выбрать город заново.
- Фото и сообщения в группах не обрабатываются.

| Ошибка | Решение |
|---|---|
| Telegram 401 | Проверить токен |
| Telegram 409 | Остановить вторую копию бота и проверить webhook |
| Город не найден | Уточнить название или использовать латиницу |
| Погодный сервис недоступен | Повторить запрос позже |
